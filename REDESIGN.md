# Portfolio redesign (2026)

This branch replaces the résumé-style homepage with a proof-of-work-oriented, minimal static website.

## Review / maintenance

- No build tooling or client-side framework is required. Open `index.html` or `jp.html` locally.
- EN/JP pages share `assets/css/styles.css` and `assets/js/site.js`.
- Review personal/project claims before publishing; the quantified Lambda result is a self-reported project outcome, not an externally audited benchmark.
- Private company work is purposefully not linked to public source code.
- Add verified public screenshots, code links, or first-person case studies as they become available. No placeholder live demos or invented adoption figures have been added.
- `profile.json` and `llms.txt` expose a concise machine-readable summary; they do not represent a chatbot.
- Older unused assets remain in the repository for easy rollback; external Bootstrap/jQuery dependencies were removed from the homepage.
- Change history remains in git; a dated activity feed is not fabricated.
